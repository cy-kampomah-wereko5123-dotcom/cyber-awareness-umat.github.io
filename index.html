🎓 Start New Academic Year

This will permanently delete all academic records for the current year.

⚠️ This action cannot be undone. We strongly recommend clicking Export All Data first to save a backup before proceeding.

What will be cleared:

  • 🗑 Deleted All student results & exam scores
  • 🗑 Deleted All attendance logs
  • 🗑 Deleted All assignments & uploaded files
  • 🗑 Deleted All schedule events
  • ✏️ Cleared Class topics, notes, homework & goals
  • ✅ Kept All student profiles & personal information
  • ✅ Kept All class groups & timetables
  • ✅ Kept Your account settings & preferences
