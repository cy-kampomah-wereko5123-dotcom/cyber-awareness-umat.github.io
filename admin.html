🔗 Teacher Link Code

Your School Link Code

This is the permanent code teachers enter in EduTrack to join your school

School Link Code
—

This code is permanent and unique to your school. Teachers open EduTrack, go to Settings → School Link, enter this code, and they are immediately linked to your school. No generated codes needed.

How Linking Works

1️⃣
Share the Code
Copy your school code above and share it directly with your teachers via WhatsApp, email, or in person.
2️⃣
Teacher Enters Code
The teacher opens EduTrack, navigates to Settings → School Link, and pastes the code.
3️⃣
Instantly Linked
The teacher appears in your Teacher Records automatically. They will receive your announcements and academic calendar events.
